# Repository conventions

## Agent skills

### gh-aw upgrades

Use the [gh-aw upgrade Skill](.agents/skills/upgrade-gh-aw/SKILL.md) before
assessing or implementing an upgrade of gh-aw or its selected review runtime,
including compatibility fixes during the upgrade.

### Issue tracker

Read the [issue-tracker instructions](docs/agents/issue-tracker.md) before
creating, reading, or updating engineering specs and tickets.

### Triage labels

Use the [triage-label mapping](docs/agents/triage-labels.md) when an engineering
Skill asks to classify an issue or change its triage state.

### Domain docs

Read the [domain-document instructions](docs/agents/domain.md) before exploring,
designing, or implementing a change.
