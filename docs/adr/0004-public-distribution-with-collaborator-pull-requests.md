# Public distribution with collaborator pull requests

The repository will be public under the MIT license so its reusable workflow can
be consumed outside GitHub's private same-owner sharing restrictions. It will
restrict incoming pull requests to collaborators in its own repository, without
requiring corresponding settings or author restrictions in consumer
repositories. This separates public workflow distribution from the workflow
repository's contribution policy; workflow execution authorization remains a
separate concern.

Applicable upstream copyright and permission notices must be retained when
material is copied into this repository.
