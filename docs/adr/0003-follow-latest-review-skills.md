# Follow the latest review Skills

The workflow follows the latest versions of its review Skills rather than
binding them to a workflow release or commit. This keeps upstream Skill
improvements available without maintaining a pinned Skill set, while accepting
that review criteria can change between runs of the same workflow revision.
Review plugins and their bundled reference material follow the same
latest-version policy.

Skill updates do not transfer ownership of the workflow's execution, safety,
publication, or verdict contract to those Skills.
