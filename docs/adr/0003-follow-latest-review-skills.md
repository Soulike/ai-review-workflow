# Follow the latest review Skills

Kestrel follows the latest versions of its review Skills rather than binding
them to a Kestrel release or commit. This keeps upstream Skill improvements
available without maintaining a pinned Skill set, while accepting that review
criteria can change between runs of the same Kestrel revision. The
knowledge-base plugin, including its bundled Knowledge, follows the same
latest-version policy.

Skill updates do not transfer ownership of Kestrel's execution, safety,
publication, or verdict contract to those Skills.
